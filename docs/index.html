    Arbre de décision

    On me demande quoi ? → qu'est-ce que je vérifie ? → quelle méthode j'applique

    Le réflexe quand on sèche : partir de ce qui est demandé, pas de ce qu'on se rappelle. Choisissez la question de l'énoncé, suivez les branches, survolez une méthode verte pour en voir un micro-exemple.

    01

    Généralités sur les suites

    Définir, calculer, étudier le sens de variation

    Une suite, c'est quoi ?

    Une liste infinie de nombres numérotés : u_0, u_1, u_2, u_3, ... On note u_n le terme de rang (ou d'indice) n, et (u_n) la suite entière.

    C'est simplement une fonction qui, à chaque entier n, associe un nombre. La seule différence avec une fonction classique : on ne peut y entrer que des entiers, donc on obtient des points isolés, jamais une courbe continue.

    Deux façons de la définir

    • Formule explicite — u_n = f(n). On remplace n par ce qu'on veut : u_{100} s'obtient d'un coup.
    • Par récurrence — on donne le premier terme u_0 et une relation u_{n+1} = f(u_n). Chaque terme se calcule à partir du précédent : pour avoir u_{100}, il faut les 100 d'avant.

    Sens de variation

    C'est la question « est-ce que ça monte ou ça descend ? ». On compare toujours un terme à son suivant :

    • Méthode 1 (universelle) — étudier le signe de u_{n+1} - u_n. Positif pour tout n → croissante.
    • Méthode 2 — si tous les termes sont strictement positifs, comparer @{u_{n+1}}{u_n} à 1. Plus grand que 1 → croissante.
    • Méthode 3 — si u_n = f(n) avec f une fonction croissante sur [0 ; +∞[, alors (u_n) est croissante. (Valable uniquement pour une suite explicite.)

    Une seule idée : pour savoir si ça monte, on compare un terme à son suivant. Tout le reste en découle.

    Le test de variation
    Δ = u_{n+1} − u_n
    Δ ≥ 0 pour tout n → suite croissante  ·  Δ ≤ 0 → décroissante  ·  Δ = 0 → constante.
    Variante pour les suites à termes positifs
    @{u_{n+1}}{u_n} > 1 ⟹ croissante    @{u_{n+1}}{u_n} < 1 ⟹ décroissante
    À réserver aux suites où apparaissent des puissances ou des factorielles (le quotient se simplifie tout seul).
    Ne pas confondre
    u_{n+1} ≠ u_n + 1
    u_{n+1} = le terme suivant. u_n + 1 = le terme actuel augmenté de 1. C'est la faute n°1 du chapitre.
    Exercice 1Signe de la différence

    Étudier le sens de variation de la suite définie pour n ≥ 0 par u_n = @{n − 3}{n + 1}.

    Voir le corrigé
    1
    On écrit le terme suivant en remplaçant n par n+1 partout : u_{n+1} = @{n − 2}{n + 2}.
    2
    On calcule la différence en mettant au même dénominateur :
    u_{n+1} − u_n = @{(n−2)(n+1) − (n−3)(n+2)}{(n+2)(n+1)}
    3
    On développe le numérateur seulement : (n² − n − 2) − (n² − n − 6) = 4.
    4
    Donc u_{n+1} − u_n = @{4}{(n+1)(n+2)}. Pour n ≥ 0 le dénominateur est positif, le numérateur aussi.
    La différence est strictement positive : la suite (u_n) est strictement croissante.
    Exercice 2Suite par récurrence

    Soit u_0 = 2 et u_{n+1} = 0,5 u_n + 3. Calculer u_1, u_2, u_3 puis conjecturer le comportement de la suite.

    Voir le corrigé
    1
    u_1 = 0,5 × 2 + 3 = 4
    2
    u_2 = 0,5 × 4 + 3 = 5  puis  u_3 = 0,5 × 5 + 3 = 5,5
    3
    Les écarts entre termes successifs valent 2 ; 1 ; 0,5 : ils sont positifs et divisés par 2 à chaque fois.
    Conjecture : (u_n) est croissante et semble se rapprocher de 6 sans jamais l'atteindre. On le démontrera aux parties 03, 06 et 07 — c'est le fil rouge de la fiche.
    Piège

    u_{n+1} n'est pas u_n + 1

    Pour obtenir u_{n+1} dans une formule explicite, on remplace chaque n par (n+1), avec les parenthèses.

    Piège

    Ne jamais dériver une suite

    La dérivée n'existe que pour les fonctions. Sur une suite définie par récurrence, on étudie le signe de u_{n+1} − u_n, généralement par récurrence (partie 03).

    Astuce

    Calculer 3 termes avant toute chose

    Cela coûte 30 secondes et donne la bonne conjecture (croissante ? majorée ? vers quoi ?). Toutes les questions suivantes de l'exercice ne font souvent que la démontrer.

    Au bac

    Repérer le type dès l'énoncé

    « u_n = ... avec des n » → explicite, on peut tout calculer directement. « u_{n+1} = ... avec des u_n » → récurrence, il faudra presque toujours un raisonnement par récurrence.

    02

    Suites arithmétiques et géométriques

    Les deux modèles à connaître par cœur, et leurs sommes

    L'idée en une phrase

    • Arithmétique : on ajoute toujours le même nombre r (la raison). Croissance linéaire — les points sont alignés.
    • Géométrique : on multiplie toujours par le même nombre q (la raison). Croissance exponentielle — les points s'envolent ou s'écrasent.

    Comment les reconnaître

    On ne devine pas, on calcule :

    • Si u_{n+1} − u_n donne un nombre constant (sans n dedans) → arithmétique de raison ce nombre.
    • Si @{u_{n+1}}{u_n} donne un nombre constant → géométrique de raison ce nombre.

    Attention : il faut que ce soit vrai pour tout n, pas seulement sur les trois premiers termes.

    À manipuler

    Bougez les curseurs : observez comment r et q changent complètement la nature de la suite.

    Quatre formules seulement : la relation de récurrence et la formule explicite, pour chacun des deux modèles. Les sommes viennent ensuite.

    Arithmétique · raison r
    u_{n+1} = u_n + r u_n = u_0 + n r u_n = u_p + (n − p) r
    Sens de variation : r > 0 croissante, r < 0 décroissante. Toujours.
    Géométrique · raison q
    u_{n+1} = q × u_n u_n = u_0 × q^n u_n = u_p × q^{n − p}
    Si u_0 > 0 : q > 1 croissante, 0 < q < 1 décroissante.

    Les sommes

    Somme des entiers
    1 + 2 + ... + n = @{n(n+1)}{2}
    Cas général : somme = nombre de termes × @{premier + dernier}{2}
    Somme des puissances
    1 + q + q² + ... + q^n = @{1 − q^{n+1}}{1 − q}
    (pour q ≠ 1) Cas général : somme = premier terme × @{1 − q^{nb de termes}}{1 − q}
    Le détail qui fait perdre les points
    nombre de termes = dernier indice − premier indice + 1
    De u_3 à u_{20} il y a 20 − 3 + 1 = 18 termes, pas 17.
    Exercice 1Reconnaître la nature

    Montrer que la suite définie par u_n = 3 × 2^{n+1} est géométrique. Préciser sa raison et son premier terme.

    Voir le corrigé
    1
    Tous les termes sont non nuls : on peut calculer le quotient.
    2
    @{u_{n+1}}{u_n} = @{3 × 2^{n+2}}{3 × 2^{n+1}} = 2^{(n+2) − (n+1)} = 2
    3
    Le quotient vaut 2, c'est une constante indépendante de n.
    4
    Premier terme : u_0 = 3 × 2^1 = 6.
    (u_n) est géométrique de raison q = 2 et de premier terme u_0 = 6. On peut réécrire u_n = 6 × 2^n.
    Exercice 2Calcul d'une somme

    Calculer S = 5 + 5×3 + 5×3² + ... + 5×3^{10}.

    Voir le corrigé
    1
    On identifie : somme de termes d'une suite géométrique de raison q = 3, de premier terme 5.
    2
    Nombre de termes : les exposants vont de 0 à 10, donc 10 − 0 + 1 = 11 termes.
    3
    On applique la formule :
    S = 5 × @{1 − 3^{11}}{1 − 3} = 5 × @{1 − 177 147}{−2}
    4
    S = 5 × @{177 146}{2} = 5 × 88 573
    S = 442 865.  Réflexe : la fraction @{1 − q^{nb}}{1 − q} est toujours positive, même quand q > 1 (deux nombres négatifs).
    Astuce

    Une seule formule de somme à retenir

    Premier terme × @{1 − raison^{nombre de termes}}{1 − raison}. Elle marche quel que soit l'indice de départ, ce qui évite d'apprendre trois variantes.

    Piège

    q^{n+1} ou q^{nb de termes} ?

    Dans la formule @{1 − q^{n+1}}{1 − q}, le n+1 c'est le nombre de termes de q^0 à q^n. Si la somme démarre ailleurs, recomptez.

    Piège

    Une suite géométrique n'est pas toujours croissante

    Avec u_0 < 0, tout s'inverse. Avec q < 0, les termes alternent de signe et la suite n'est ni croissante ni décroissante.

    Au bac

    La formule explicite débloque tout

    Dès qu'on a montré qu'une suite est géométrique, on écrit u_n = u_0 q^n : la limite, le sens de variation et les seuils se lisent alors directement sur q. C'est exactement le but de la partie 07.

    03

    Le raisonnement par récurrence

    La démonstration en 3 étapes, rédigée toujours pareil

    À quoi ça sert

    À démontrer qu'une propriété est vraie pour tous les entiers n, alors qu'on ne peut évidemment pas les tester un par un. C'est l'outil obligatoire dès qu'une suite est définie par récurrence.

    L'image des dominos

    Une file infinie de dominos tombe entièrement si deux conditions sont réunies : on fait tomber le premier, et chaque domino qui tombe fait tomber son voisin.

    Les 3 étapes, toujours dans cet ordre

    • Initialisation — on vérifie que la propriété est vraie au rang de départ n_0 (souvent 0 ou 1). C'est un simple calcul.
    • Hérédité — on suppose la propriété vraie pour un entier n ≥ n_0 fixé (c'est l'hypothèse de récurrence), et on démontre qu'elle est alors vraie au rang n+1.
    • Conclusion — la propriété est vraie au rang de départ et elle se transmet : elle est vraie pour tout n ≥ n_0.

    Le cœur du travail est toujours l'hérédité : on part de l'hypothèse et on la transforme jusqu'à obtenir la propriété au rang suivant.

    Ici il n'y a rien à calculer : ce qui est noté, c'est la rédaction. Apprenez le squelette, il est identique dans tous les sujets.

    Le squelette de rédaction — à recopier tel quel

    Soit P(n) la propriété : « … ».
    Initialisation. Pour n = 0 : … donc P(0) est vraie.
    Hérédité. Supposons que pour un certain entier n ≥ 0, P(n) est vraie, c'est-à-dire …
    Montrons que P(n+1) est vraie, c'est-à-dire …
    [transformations à partir de l'hypothèse]
    Donc P(n+1) est vraie.
    Conclusion. P(0) est vraie et P est héréditaire, donc par récurrence P(n) est vraie pour tout n ≥ 0.

    Les deux formulations à distinguer
    Hypothèse (ce qu'on a le droit d'utiliser) : « pour un certain entier n ».
    Conclusion (ce qu'on démontre) : « pour tout entier n ».
    Écrire « supposons que pour tout n… » revient à supposer ce qu'on veut démontrer : la démonstration ne vaut plus rien.
    Exercice 1Récurrence sur une inégalité

    Soit u_0 = 2 et u_{n+1} = 0,5 u_n + 3. Démontrer que pour tout n ≥ 0, u_n ≤ 6.

    Voir le corrigé
    1
    Propriété P(n) : « u_n ≤ 6 ».
    2
    Initialisation. u_0 = 2 ≤ 6 : P(0) est vraie.
    3
    Hérédité. Supposons u_n ≤ 6 pour un certain n ≥ 0. On part de l'hypothèse et on fabrique u_{n+1} :
    u_n ≤ 6 ⟹ 0,5 u_n ≤ 3 ⟹ 0,5 u_n + 3 ≤ 6 (on multiplie par 0,5 > 0 : le sens de l'inégalité est conservé, puis on ajoute 3 des deux côtés)
    4
    Or 0,5 u_n + 3 = u_{n+1}, donc u_{n+1} ≤ 6 : P(n+1) est vraie.
    Conclusion. Par récurrence, u_n ≤ 6 pour tout n ≥ 0 : la suite est majorée par 6.
    Exercice 2Récurrence avec une puissance

    Démontrer que pour tout entier n ≥ 0 : 2^n ≥ n + 1.

    Voir le corrigé
    1
    Initialisation. 2^0 = 1 et 0 + 1 = 1, donc 2^0 ≥ 1 : vrai au rang 0.
    2
    Hérédité. Supposons 2^n ≥ n + 1 pour un certain n ≥ 0.
    3
    On fait apparaître 2^{n+1} en multipliant l'hypothèse par 2 :
    2^{n+1} = 2 × 2^n ≥ 2(n + 1) = 2n + 2
    4
    Reste à comparer à la cible n + 2 : 2n + 2 − (n + 2) = n ≥ 0, donc 2n + 2 ≥ n + 2.
    5
    Par transitivité : 2^{n+1} ≥ n + 2, soit P(n+1).
    Conclusion. Pour tout n ≥ 0, 2^n ≥ n + 1. Ce résultat sert à prouver que 2^n → +∞ par comparaison (partie 05).
    Astuce

    Écrire la cible avant de chercher

    Notez tout de suite ce que vous devez obtenir (« montrons que u_{n+1} ≤ 6 »). Vous saurez alors quelle opération appliquer à l'hypothèse pour y arriver : c'est un problème de trajet entre deux points connus.

    Piège

    Partir du résultat

    On ne part jamais de u_{n+1} ≤ 6 pour redescendre. On part de l'hypothèse u_n ≤ 6 et on avance. Sinon on suppose vrai ce qu'on doit prouver.

    Piège

    Multiplier par un nombre négatif

    Cela inverse l'inégalité. Repérez le signe du coefficient avant de transformer l'hypothèse.

    Au bac

    Points faciles garantis

    L'initialisation et la conclusion valent des points même si l'hérédité bloque. Rédigez-les toujours, et n'oubliez jamais la phrase de conclusion : elle est notée.

    04

    Limites d'une suite

    Converger, diverger, et lever les formes indéterminées

    La question posée

    « Que deviennent les termes quand n devient immense ? » Trois réponses possibles, et trois seulement :

    • Ils se stabilisent autour d'un nombre ℓ : la suite converge vers ℓ. On note lim u_n = ℓ.
    • Ils explosent vers +∞ (ou −∞) : la suite diverge vers l'infini.
    • Ils oscillent sans se fixer, comme (−1)^n qui vaut 1, −1, 1, −1, ... : la suite n'a pas de limite.

    Vocabulaire du bac : « diverger » ne veut pas dire « partir à l'infini ». Cela veut dire « ne pas converger » — les cas 2 et 3 sont tous les deux des divergences.

    Converger, visuellement

    Dire que u_n → ℓ signifie : quelle que soit la bande, aussi fine soit-elle, tracée autour de ℓ, tous les termes finissent par y entrer et n'en ressortent plus.

    Comment on calcule une limite

    • On remplace chaque morceau par sa limite usuelle (tableau ci-contre, onglet Formules).
    • On combine avec les règles d'opérations.
    • Si on tombe sur une des 4 formes indéterminées, le calcul direct est interdit : il faut transformer l'écriture avant de conclure.

    La technique n°1 : factoriser par le terme dominant (celui de plus haut degré), au numérateur comme au dénominateur, puis simplifier.

    Deux choses à savoir par cœur : les limites usuelles (les briques de base) et les 4 formes indéterminées (elles disent quand le calcul direct est interdit). Le reste se déduit.

    Les 4 formes indéterminées
    ∞ − ∞    0 × ∞    @{∞}{∞}    @{0}{0}
    « Indéterminé » ne veut pas dire « pas de limite » : cela veut dire que le calcul brut ne suffit pas. La parade : factoriser par le terme dominant, ou passer par la quantité conjuguée s'il y a une racine.

    Les briques de base

    Vers +∞
    n → +∞   n² → +∞   n^k → +∞   √n → +∞
    Vers 0
    @{1}{n} → 0   @{1}{n²} → 0   @{1}{√n} → 0

    Opérations sur les limites

    Tout se comporte comme on l'espère — sauf les cases orange, qui sont exactement les 4 formes indéterminées.

    Somme
    ℓ + ℓ'ℓ + ℓ'
    ℓ + (+∞)+∞
    (+∞) + (+∞)+∞
    (+∞) + (−∞)F. I.
    Produit
    ℓ × ℓ'ℓ × ℓ'
    ℓ ≠ 0  fois  ±∞±∞
    ∞ × ∞∞
    0 × ∞F. I.
    Quotient
    @{ℓ}{ℓ'}@{ℓ}{ℓ'}
    @{ℓ}{±∞}0
    @{±∞}{ℓ}±∞

    Pour les cases ±∞, le signe se détermine à part, avec la règle des signes.

    Exercice 1Factoriser par le terme dominant

    Déterminer lim u_n avec u_n = @{3n² − n + 1}{n² + 5}.

    Voir le corrigé
    1
    Numérateur et dénominateur tendent vers +∞ : forme indéterminée @{∞}{∞}. Calcul direct interdit.
    2
    On factorise haut et bas par n², le terme de plus haut degré :
    u_n = @{n²(3 − @{1}{n} + @{1}{n²})}{n²(1 + @{5}{n²})}
    3
    On simplifie par n² (non nul) : u_n = @{3 − @{1}{n} + @{1}{n²}}{1 + @{5}{n²}}
    4
    Chaque @{1}{n^k} tend vers 0 : le numérateur tend vers 3, le dénominateur vers 1.
    lim u_n = 3. La suite converge vers 3.
    Raccourci de vérification : pour un quotient de polynômes en n, la limite est celle du quotient des termes de plus haut degré, ici @{3n²}{n²} = 3.
    Exercice 2Quantité conjuguée

    Déterminer lim u_n avec u_n = √(n+1) − √n.

    Voir le corrigé
    1
    Les deux racines tendent vers +∞ : forme indéterminée ∞ − ∞.
    2
    On multiplie et divise par la quantité conjuguée √(n+1) + √n (on change les signes entre les deux termes) :
    u_n = @{(√(n+1) − √n)(√(n+1) + √n)}{√(n+1) + √n}
    3
    Le numérateur est une identité remarquable (a − b)(a + b) = a² − b² :
    = @{(n + 1) − n}{√(n+1) + √n} = @{1}{√(n+1) + √n}
    4
    Le dénominateur tend vers +∞, le numérateur est constant : on est en @{1}{+∞}.
    lim u_n = 0. Les deux racines partent bien à l'infini, mais l'écart entre elles se réduit vers 0.
    Astuce

    Quotient de polynômes = plus haut degré

    Pour un quotient de polynômes en n, la limite est celle de @{terme dominant du haut}{terme dominant du bas}. Utilisez-le pour prévoir le résultat, mais rédigez la factorisation : c'est elle qui est notée.

    Astuce

    Une racine dans une différence → conjuguée

    Réflexe automatique dès qu'une forme ∞ − ∞ contient un √. On multiplie par le conjugué en haut et en bas.

    Piège

    « ∞ − ∞ = 0 » est faux

    De même @{∞}{∞} ≠ 1 et 0 × ∞ ≠ 0. L'infini n'est pas un nombre : on ne calcule pas avec. Écrire l'une de ces égalités coûte tous les points de la question.

    Piège

    Diverger ≠ tendre vers l'infini

    (−1)^n diverge et pourtant reste coincée entre −1 et 1. Une suite bornée peut parfaitement ne pas avoir de limite.

    Au bac

    Toujours annoncer la forme indéterminée

    La phrase « il s'agit d'une forme indéterminée @{∞}{∞}, on factorise par n² » vaut un point à elle seule et structure tout le reste.

    05

    Limites par comparaison

    Encadrer quand le calcul direct est impossible — et le cas de qn

    Quand les utiliser

    Dès qu'apparaît un morceau impossible à calculer directement : (−1)^n, sin(n), cos(n), ou une expression qu'on ne sait pas simplifier. L'idée : on ne calcule pas la suite, on la coince entre des suites qu'on connaît.

    Théorèmes de comparaison — pour l'infini

    • Si u_n ≥ v_n (à partir d'un certain rang) et v_n → +∞, alors u_n → +∞. On pousse par en dessous.
    • Si u_n ≤ v_n et v_n → −∞, alors u_n → −∞. On écrase par au-dessus.

    Théorème des gendarmes — pour une limite finie

    Si v_n ≤ u_n ≤ w_n à partir d'un certain rang, et si v_n et w_n tendent vers la même limite ℓ, alors u_n → ℓ.

    Le cas q^n

    C'est la limite la plus rentable du chapitre : toute suite géométrique s'y ramène. Tout dépend de la position de q par rapport à 1 et −1.

    Deux théorèmes qui se choisissent en une seconde : limite infinie → comparaison ; limite finie → gendarmes. Puis le tableau de q^n, la ligne la plus rentable du chapitre.

    Comparaison · vers l'infini
    u_n ≥ v_n  et  v_n → +∞  ⟹  u_n → +∞ u_n ≤ v_n  et  v_n → −∞  ⟹  u_n → −∞
    Une seule inégalité suffit.
    Gendarmes · vers une limite finie
    v_n ≤ u_n ≤ w_n v_n → ℓ  et  w_n → ℓ  ⟹  u_n → ℓ
    Il faut un encadrement complet et surtout la même limite des deux côtés.

    Limite de q^n — à connaître par cœur

    Valeur de qLimite de qnComportement
    q > 1+∞explose
    q = 11constante
    −1 < q < 10s'écrase vers 0
    q ≤ −1pas de limiteoscille
    Les deux encadrements de base
    −1 ≤ (−1)^n ≤ 1   ·   −1 ≤ sin(n) ≤ 1   ·   −1 ≤ cos(n) ≤ 1
    Tout exercice de gendarmes démarre par l'une de ces trois lignes.
    Exercice 1Comparaison

    Déterminer la limite de u_n = n + (−1)^n.

    Voir le corrigé
    1
    Le terme (−1)^n n'a pas de limite : impossible d'utiliser les opérations sur les limites.
    2
    On part de l'encadrement de base −1 ≤ (−1)^n, et on ajoute n des deux côtés :
    u_n = n + (−1)^n ≥ n − 1
    3
    Or n − 1 → +∞.
    Par comparaison, lim u_n = +∞.
    Ici on cherche l'infini : un minorant suffit, pas besoin d'encadrer des deux côtés.
    Exercice 2Gendarmes

    Déterminer la limite de u_n = @{sin(n)}{n} pour n ≥ 1.

    Voir le corrigé
    1
    On écrit l'encadrement de base : −1 ≤ sin(n) ≤ 1.
    2
    On divise par n, strictement positif pour n ≥ 1, donc le sens des inégalités est conservé :
    −@{1}{n} ≤ @{sin(n)}{n} ≤ @{1}{n}
    3
    Les deux bornes tendent vers la même limite : −@{1}{n} → 0 et @{1}{n} → 0.
    D'après le théorème des gendarmes, lim u_n = 0.
    Astuce

    Choisir le bon théorème en une seconde

    La limite cherchée est infinie → comparaison, une seule inégalité. La limite cherchée est finie → gendarmes, encadrement des deux côtés.

    Astuce

    Toujours démarrer de l'encadrement connu

    On n'invente pas les bornes : on part de −1 ≤ (−1)^n ≤ 1 (ou sin, ou cos) et on applique à cet encadrement exactement les opérations qui construisent u_n.

    Piège

    Diviser sans vérifier le signe

    Diviser un encadrement par un nombre négatif inverse les inégalités. Précisez toujours « n > 0 donc le sens est conservé » : c'est un point de rédaction.

    Piège

    Des gendarmes qui ne convergent pas au même endroit

    Si v_n → 0 et w_n → 2, le théorème ne dit rien. Même limite des deux côtés, sinon l'encadrement est inutile.

    Au bac

    Le réflexe 0 < q < 1

    Dès qu'un 0,5^n, (@{2}{3})^n ou 0,9^n apparaît, écrivez « −1 < q < 1 donc q^n → 0 ». C'est la clé de la quasi-totalité des conclusions de limites du chapitre.

    06

    Suites bornées et convergence monotone

    Prouver qu'une limite existe — puis aller la chercher

    Le vocabulaire

    • Majorée : il existe un nombre M tel que u_n ≤ M pour tout n. Un plafond que la suite ne franchit jamais.
    • Minorée : il existe m tel que u_n ≥ m pour tout n. Un plancher.
    • Bornée : les deux à la fois.

    Ces majorants se démontrent presque toujours par récurrence (partie 03).

    Le théorème de la convergence monotone

    Une suite croissante et majorée converge. Intuitivement : elle monte, mais elle ne peut pas dépasser le plafond — elle n'a donc pas d'autre choix que de se stabiliser.

    Symétriquement, une suite décroissante et minorée converge.

    Cas divergent : une suite croissante non majorée tend vers +∞. Rien ne la retient.

    Le théorème donne l'existence, pas la valeur

    Point capital : il garantit qu'une limite existe, sans dire laquelle. Une suite majorée par 6 peut converger vers 5, vers 4, vers 0…

    Pour obtenir la valeur, deux voies :

    • Le point fixe — si u_{n+1} = f(u_n) converge vers ℓ et que f est continue, alors ℓ vérifie ℓ = f(ℓ). On résout cette équation.
    • La suite auxiliaire — on fabrique une suite géométrique à partir de u_n, et on obtient la formule explicite (partie 07).

    Un théorème, et une mise en garde qui vaut des points : il prouve qu'une limite existe, il ne la calcule pas.

    Théorème de la convergence monotone
    croissante + majorée ⟹ converge décroissante + minorée ⟹ converge
    Et si la limite est ℓ, alors ℓ ≤ M — mais pas ℓ = M.
    Cas divergent
    croissante + non majorée ⟹ u_n → +∞ décroissante + non minorée ⟹ u_n → −∞
    Équation du point fixe
    u_{n+1} = f(u_n)  et  u_n → ℓ  ⟹  ℓ = f(ℓ)
    On passe à la limite des deux côtés de la relation de récurrence : u_{n+1} et u_n ont la même limite ℓ. Valable seulement si l'on a déjà prouvé que la suite converge.
    Exercice 1Le raisonnement complet en 3 temps

    Soit u_0 = 2 et u_{n+1} = 0,5 u_n + 3. Montrer que (u_n) converge et déterminer sa limite.

    Voir le corrigé
    1
    Majorée. Démontré par récurrence en partie 03 : u_n ≤ 6 pour tout n.
    2
    Croissante. On calcule la différence en utilisant la relation de récurrence :
    u_{n+1} − u_n = 0,5 u_n + 3 − u_n = 3 − 0,5 u_n = 0,5(6 − u_n) Or u_n ≤ 6, donc 6 − u_n ≥ 0 : la différence est positive, la suite est croissante.
    3
    Convergence. Croissante et majorée par 6 : d'après le théorème de la convergence monotone, (u_n) converge vers un réel ℓ ≤ 6.
    4
    Valeur. La fonction f(x) = 0,5x + 3 est continue. On passe à la limite :
    ℓ = 0,5 ℓ + 3 ⟺ 0,5 ℓ = 3 ⟺ ℓ = 6
    (u_n) converge et lim u_n = 6.
    Remarquez l'astuce de l'étape 2 : factoriser la différence pour faire apparaître 6 − u_n, dont on connaît déjà le signe.
    Exercice 2Vrai ou faux — comprendre le théorème

    « Une suite croissante et majorée par 10 converge vers 10. » Vrai ou faux ?

    Voir le corrigé
    1
    Faux. Il suffit d'un contre-exemple.
    2
    Prenons u_n = 1 − @{1}{n} pour n ≥ 1. Elle est croissante (puisque @{1}{n} décroît) et majorée par 10.
    3
    Pourtant lim u_n = 1 ≠ 10.
    Le théorème garantit seulement que la limite existe et qu'elle est ≤ au majorant. Un majorant n'est pas la limite — il y en a même une infinité (10, 100, 1000…).
    Astuce

    Le plan type d'un exercice de bac

    (1) conjecturer avec les premiers termes, (2) majorer par récurrence, (3) montrer la monotonie, (4) conclure par le théorème, (5) calculer la limite par point fixe ou suite auxiliaire. Presque tous les exercices suivent ces cinq questions.

    Astuce

    Le majorant est offert par l'énoncé

    Quand on vous demande de montrer u_n ≤ 6, c'est que 6 est la limite. Inversement, si l'on cherche le majorant, résolvez ℓ = f(ℓ) au brouillon : la solution est le bon candidat.

    Piège

    Le point fixe suppose la convergence

    Écrire ℓ = f(ℓ) avant d'avoir prouvé que la suite converge est un raisonnement faux : une suite divergente n'a pas de ℓ à substituer. L'ordre des questions est imposé.

    Piège

    Majorée ne suffit pas

    (−1)^n est bornée et ne converge pas. Il faut monotone ET bornée du bon côté : les deux hypothèses, toujours.

    07

    Suite auxiliaire et recherche de seuil

    La méthode passe-partout du bac, et l'algorithme Python

    Le problème

    La suite u_{n+1} = a u_n + b (dite arithmético-géométrique) n'est ni arithmétique ni géométrique : on ne sait donc pas écrire sa formule explicite. La parade : fabriquer à côté une suite (v_n), elle, géométrique.

    La méthode en 4 temps

    • 1. On trouve le point fixe ℓ en résolvant ℓ = a ℓ + b. (L'énoncé le donne souvent directement.)
    • 2. On pose v_n = u_n − ℓ et on démontre que (v_n) est géométrique, en calculant v_{n+1} et en le ramenant à a × v_n.
    • 3. On écrit la formule explicite v_n = v_0 × a^n.
    • 4. On revient à u_n : puisque v_n = u_n − ℓ, on a u_n = v_n + ℓ. La limite se lit alors sur a^n.

    La recherche de seuil

    Question classique : « à partir de quel rang u_n dépasse-t-il telle valeur ? ». Deux façons de répondre :

    • Par le calcul — on résout l'inéquation à partir de la formule explicite (souvent avec le logarithme).
    • Par un algorithme — une boucle while qui avance tant que la condition n'est pas atteinte. C'est ce que demande le sujet la plupart du temps.

    Une méthode, toujours la même, et l'algorithme de seuil qui l'accompagne.

    Suite arithmético-géométrique
    u_{n+1} = a u_n + b   →   poser   v_n = u_n − ℓ   où   ℓ = a ℓ + b
    Alors (v_n) est géométrique de raison a, et :
    u_n = (u_0 − ℓ) × a^n + ℓ
    Si −1 < a < 1, alors a^n → 0 et u_n → ℓ. La limite est le point fixe.
    Algorithme de seuil · Python
    u = 2 n = 0 while u <= 5.9: u = 0.5 * u + 3 n = n + 1 print(n) # renvoie 6
    La variable u est écrasée à chaque tour (elle ne retient que le terme courant), et n compte les tours. La boucle s'arrête dès que la condition devient fausse : n contient alors le premier rang qui convient.
    Exercice 1Suite auxiliaire

    Soit u_0 = 2 et u_{n+1} = 0,5 u_n + 3. On pose v_n = u_n − 6.
    Montrer que (v_n) est géométrique, puis exprimer u_n en fonction de n et retrouver la limite.

    Voir le corrigé
    1
    On part de v_{n+1} et on remplace u_{n+1} par son expression :
    v_{n+1} = u_{n+1} − 6 = 0,5 u_n + 3 − 6 = 0,5 u_n − 3
    2
    On factorise par 0,5 pour faire apparaître u_n − 6 :
    v_{n+1} = 0,5(u_n − 6) = 0,5 v_n (v_n) est donc géométrique de raison q = 0,5, avec v_0 = u_0 − 6 = −4.
    3
    Formule explicite : v_n = −4 × 0,5^n.
    4
    Retour à u_n : u_n = v_n + 6, donc u_n = 6 − 4 × 0,5^n (vérification : u_0 = 6 − 4 = 2 ✓   u_1 = 6 − 2 = 4 ✓)
    5
    Comme −1 < 0,5 < 1, on a 0,5^n → 0, donc 4 × 0,5^n → 0.
    lim u_n = 6. On retrouve le résultat de la partie 06, mais cette fois avec la formule explicite, qui permet en plus de calculer n'importe quel terme et de résoudre les seuils.
    Exercice 2Seuil

    Avec u_n = 6 − 4 × 0,5^n, déterminer le plus petit entier n tel que u_n > 5,9.

    Voir le corrigé
    1
    On traduit l'inéquation :
    6 − 4 × 0,5^n > 5,9 ⟺ −4 × 0,5^n > −0,1
    2
    On divise par −4 : attention, nombre négatif, l'inégalité change de sens.
    0,5^n < 0,025
    3
    On teste à la calculatrice : 0,5^5 = 0,031 25 (trop grand) et 0,5^6 = 0,015 625 < 0,025 ✓
    4
    Vérification sur la suite : u_5 = 5,875 et u_6 = 5,937 5 > 5,9.
    Le plus petit rang est n = 6. L'algorithme Python de l'onglet Formules renvoie exactement cette valeur.
    Astuce

    L'énoncé vous souffle le v_n

    « On pose v_n = u_n − 6 » : le 6 est le point fixe, et c'est la limite. Vous connaissez donc la réponse finale avant même de commencer.

    Astuce

    Toujours partir de v_{n+1}

    On écrit v_{n+1} = u_{n+1} − ℓ, on remplace u_{n+1}, puis on factorise pour reconstituer v_n. Ce mouvement est identique dans tous les sujets.

    Astuce

    Vérifier avec u_0

    Une fois la formule explicite trouvée, testez-la sur n = 0 et n = 1. Dix secondes pour détecter une erreur de signe qui ferait perdre toute la suite de l'exercice.

    Piège

    Oublier de revenir à u_n

    La question porte sur u_n, pas sur v_n. Terminez toujours par u_n = v_n + ℓ.

    Au bac

    Boucle while, jamais for

    On ne connaît pas d'avance le nombre de tours : c'est précisément ce qu'on cherche. La condition du while est la négation de l'objectif (« tant que ce n'est pas encore atteint »).

    Exercices mixtes

    Dix questions courtes, toutes parties mélangées — pour vérifier que les réflexes sont là

    Contrairement aux exercices des parties, ceux-ci ne vous disent pas quelle méthode appliquer : c'est justement ce qu'il faut retrouver. Si vous bloquez, l'arbre de décision est fait pour ça.

    1partie 02

    Nature de la suite u_n = 5 − 3n ?

    Réponse
    1
    u_{n+1} − u_n = 5 − 3(n+1) − (5 − 3n) = −3
    2
    La différence est constante, indépendante de n.
    Arithmétique de raison r = −3, de premier terme u_0 = 5. Donc décroissante, et u_n → −∞.
    2partie 04

    lim @{2n + 1}{3n − 4}

    Réponse
    1
    Forme indéterminée @{∞}{∞}.
    2
    On factorise haut et bas par n : @{n(2 + @{1}{n})}{n(3 − @{4}{n})}
    lim = @{2}{3} — le quotient des termes de plus haut degré.
    3partie 01

    Sens de variation de u_n = @{n}{n + 1} ?

    Réponse
    1
    u_{n+1} − u_n = @{n+1}{n+2} − @{n}{n+1}
    2
    Même dénominateur : @{(n+1)² − n(n+2)}{(n+1)(n+2)} = @{1}{(n+1)(n+2)}
    Strictement positif : la suite est croissante. (Elle converge vers 1.)
    4partie 05

    lim (3 × 0,8^n − 2)

    Réponse
    1
    On regarde la raison : −1 < 0,8 < 1.
    2
    Donc 0,8^n → 0, puis 3 × 0,8^n → 0.
    lim = −2. La suite converge.
    5partie 04

    lim (n² − n)

    Réponse
    1
    Forme indéterminée ∞ − ∞ : interdit de conclure directement.
    2
    On factorise par le terme dominant : n²(1 − @{1}{n})
    3
    n² → +∞ et 1 − @{1}{n} → 1.
    lim = +∞. Le carré l'emporte toujours sur le terme de degré 1.
    6partie 05

    lim (2 + @{(−1)^n}{n})

    Réponse
    1
    (−1)^n n'a pas de limite : on encadre.
    2
    −@{1}{n} ≤ @{(−1)^n}{n} ≤ @{1}{n}, et les deux bornes tendent vers 0.
    Par les gendarmes le terme tend vers 0, donc lim = 2.
    7partie 02

    1 + 2 + 3 + ... + 100

    Réponse
    1
    Somme des 100 premiers entiers : @{n(n+1)}{2} avec n = 100.
    @{100 × 101}{2} = 5 050.
    8partie 07

    u_{n+1} = 3u_n − 4. On pose v_n = u_n − 2. Nature de (v_n) ?

    Réponse
    1
    v_{n+1} = u_{n+1} − 2 = 3u_n − 4 − 2 = 3u_n − 6
    2
    On factorise par 3 : v_{n+1} = 3(u_n − 2) = 3 v_n
    Géométrique de raison 3. Le 2 vient du point fixe ℓ = 3ℓ − 4. Comme 3 > 1, la suite diverge (sauf si u_0 = 2).
    9partie 06

    Vrai ou faux : « toute suite bornée converge ».

    Réponse
    1
    On cherche un contre-exemple.
    2
    u_n = (−1)^n reste entre −1 et 1 : elle est bornée.
    Faux. Elle n'a pas de limite. Il faut monotone ET bornée — les deux.
    10partie 03

    u_0 = 1 et u_{n+1} = √(u_n + 2). Montrer que 0 ≤ u_n ≤ 2.

    Réponse
    1
    Init. u_0 = 1 : encadré. ✓
    2
    Hérédité. On suppose 0 ≤ u_n ≤ 2, on ajoute 2 : 2 ≤ u_n + 2 ≤ 4
    3
    La racine est croissante : √2 ≤ √(u_n + 2) ≤ 2
    Or √2 ≥ 0, donc 0 ≤ u_{n+1} ≤ 2. Conclusion : vrai pour tout n par récurrence.
